# Калькулятор процентов — десктопное приложение на Python

Три типа вычислений:
- Процент от числа (X% от Y)
- Процентное соотношение (A — это сколько % от B?)
- Увеличение / уменьшение на процент

## Запуск

```bash
python percent_calculator.py
```

## Сборка в `.exe`

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name PercentCalculator percent_calculator.py
```
